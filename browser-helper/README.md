# Sift Browser Helper

当 Vercel 的数据中心出口被 YouTube 风控时，本扩展使用用户本机 Chrome 的网络读取公开视频字幕或故事板，再交给 Sift 生成摘要。扩展只响应 Sift 生产站点和本地开发地址发起的请求。

## 本地安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `browser-helper` 文件夹。
5. 刷新 Sift 页面并重新分析 YouTube 链接。

ChatGPT/Codex 浏览器扩展不包含 Sift 所需的 YouTube 域名权限，不能替代本扩展。

## 能力边界

- 有公开字幕：直接读取字幕和时间戳。
- 无公开字幕但画面有硬字幕：读取低分辨率故事板并交给模型识别。
- 无公开字幕且画面没有文字：当前无法还原纯语音内容，后续需要增加音频转写。
