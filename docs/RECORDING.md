# 线上操作录制

录制对象为 https://sift-navy-six.vercel.app/，使用全新浏览器会话，不加载个人登录状态或本地 `.env`。脚本点击真实页面并调用线上解析接口，可能消耗已配置的字幕和模型服务额度；不拦截接口、不替换摘要内容。画面中的中文步骤字幕由录制脚本添加，不是产品界面功能。

## 重新录制

```sh
npm install
npx playwright install chromium
node scripts/record-demo.mjs
```

可通过第一个参数指定已授权处理的公开视频链接。默认使用约两分钟的 Git 教学视频，选择简洁摘要，每次运行最多提交一次解析请求；失败不会覆盖成功视频。

可选环境变量：`RECORDING_PROXY` 指定浏览器代理；`RECORDING_BROWSER` 指定已有 Chromium 可执行文件。代理只用于录制浏览器，不改变线上服务配置。

输出：

- `docs/media/sift-youtube-demo.webm`：完整操作录像。
- `docs/media/sift-youtube-poster.png`：结果页截图封面。
- 临时目录：原始录像及导出的 `summary.md`，位置输出到终端，不提交到 Git。

后续重录会更新视频和封面，提交前请检查内容与敏感信息。GitHub 客户端无法直接播放 WebM 时，可下载后用浏览器或播放器打开。
